CNC Turning Program Generator - Rough, Facing, Finish, Drill, ID Boring, Groove, Parting

Learning to write manual CNC turning programs by hand typically takes 3.5+ years of shop-floor experience. CAM software gets you there faster, but needs heavy computer-graphics knowledge, a paid license, and a post-processor setup. CNC Code Lab skips both - upload a DXF drawing, or build the 2D profile directly in the tool, and get a complete turning program in your browser, free.

What it generates

  • Rough turning passes
  • Facing
  • Finishing passes
  • Drilling
  • ID boring
  • Grooving
  • Parting / cut-off

Two ways to start

Upload a DXF drawing and let the tool detect the profile and dimensions, or build the 2D profile yourself directly inside the editor if you don't have a DXF file. Either way, you get a program covering the full turning sequence, not just one operation.

Write, verify, or simulate your own code too

Already have a program written by hand? Paste it in to verify and simulate the toolpath before running it. Or write a new program manually in the editor and simulate it the same way. When you're ready, download the final code in NC or text format to load straight onto the machine.

No CAM software required

No license, no post-processor, no CAM training curve - the entire workflow runs in the browser.

The logic behind this tool was written from scratch by a CNC programmer/machinist with 10+ years of hands-on manual G-code and CAM experience, and the generated programs have been validated by running them on real production machines - not just simulated.
